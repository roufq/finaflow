🚀 FinaFlow Pro

Official Documentation v1.0

Sistem Manajemen Keuangan Pintar Berbasis Laravel 12

📌 Tentang Produk

Terima kasih telah membeli FinaFlow Pro. Aplikasi ini dirancang untuk memberikan kemudahan dalam mengelola kekayaan, melacak investasi, dan memahami kebiasaan finansial secara mendalam.

⚙️ Prasyarat Sistem

  • PHP: 8.2 atau 8.3 (Wajib)
  • Web Server: Apache (cPanel) atau Nginx (VPS)
  • Database: MySQL 8.0+ atau MariaDB
  • Ekstensi PHP: BCMath, CType, cURL, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML

⚡ Panduan Instalasi (Auto-Installer)

1
Upload File: Ekstrak file .zip dan upload isinya ke folder public_html hosting Anda.
2
Buat Database: Buat database baru di MySQL Databases cPanel Anda.
3
Jalankan Wizard: Buka domain Anda (misal: domainanda.com) di browser.
4
Input Detail: Ikuti langkah-langkah di layar, masukkan detail database, dan buat akun Admin.

📂 Konfigurasi Awal

Setelah login pertama kali, segera lakukan hal berikut:

  • Buka menu Settings untuk mengatur simbol mata uang (seperti IDR).
  • Aktifkan Two-Factor Authentication di profil untuk keamanan tambahan.
  • Gunakan fitur Web Sync jika ingin menghubungkan bank secara otomatis (memerlukan API Key).

🛡️ Dukungan & Update

Sebagai pembeli resmi di P-Store, Anda berhak mendapatkan update seumur hidup secara gratis.

Fitur Chat: Langsung melalui dashboard P-Store jika Anda mengalami kendala instalasi.
