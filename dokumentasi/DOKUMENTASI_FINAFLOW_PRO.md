# 🚀 FinaFlow Pro: Dokumentasi Resmi
**Versi:** 1.0.0 | **Framework:** Laravel 12 | **Target:** P-Store Buyer

Selamat datang di **FinaFlow Pro**! Dokumen ini berisi panduan lengkap untuk melakukan instalasi dan konfigurasi awal aplikasi.

---

## 📋 Prasyarat Sistem
Pastikan server Anda memenuhi spesifikasi berikut:
- **PHP:** 8.2 atau 8.3 (Sangat Disarankan)
- **Database:** MySQL 8.0+, MariaDB, atau SQLite
- **Ekstensi PHP:** BCMath, CType, cURL, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML
- **Web Server:** Apache atau Nginx

---

## ⚡ Instalasi Cepat (Auto-Installer)
*Metode termudah untuk pengguna hosting/cPanel.*

1. **Upload:** Upload file `.zip` ke folder `public_html` dan ekstrak.
2. **Database:** Buat database MySQL baru di cPanel.
3. **Browser:** Buka domain Anda di browser.
4. **Wizard:** Ikuti instruksi di layar untuk menghubungkan database dan membuat akun Admin.

---

## ⚙️ Konfigurasi Penting
Setelah instalasi selesai:
1. **Mata Uang:** Masuk ke menu **Settings** > **Currency** untuk mengubah ke IDR (Rupiah).
2. **Keamanan:** Buka profil Anda dan aktifkan **Two-Factor Authentication (2FA)**.
3. **Optimasi:** Masuk ke menu **Analytics** untuk melihat proyeksi keuangan Anda.

---
